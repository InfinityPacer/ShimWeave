# FFmpeg

ShimWeave 的 TrueHD 解码使用 FFmpeg 9.0.2 的 libavcodec 与 libavutil，编译为 WebAssembly 随扩展分发，
按 GNU Lesser General Public License 2.1 或更高版本授权，许可全文见同目录的 COPYING.LGPLv2.1。

- 源码：https://ffmpeg.org/releases/ffmpeg-9.0.2.tar.xz
- 重建脚本与桥接代码：https://github.com/InfinityPacer/ShimWeave 的 packages/codec-truehd
