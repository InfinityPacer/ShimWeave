# 性能基线

基线日期为 2026-09-04。性能是 ShimWeave 的首要约束，媒体数据必须保持
`源站/CDN → 浏览器`，不得经过 Gateway、NAS、云端中继或扩展消息的 Base64 通道。

## 默认边界

| 项目 | 默认值 |
| --- | ---: |
| 全局 Range 并发 | 6 |
| 单媒体源 Range 并发 | 2 |
| 等待任务上限 | 256 |
| 单媒体源 LRU | 16 MiB / 256 条 |
| MSE 前向窗口 | 90 秒 |
| MSE 后向窗口 | 30 秒 |
| MSE 近似字节预算 | 128 MiB |

本地媒体和浏览器原生可播内容不得创建 ShimWeave 媒体会话、Worker、媒体探测或额外 Range
请求。快速切换、Seek 和关闭页面必须取消旧会话，不能留下后台下载。

## 当前测量结果

### 浏览器媒体管线

| 场景 | 结果 |
| --- | --- |
| 本地冷启动 | 458 ms 开始推进 |
| 79 秒样本连续播放 | 4 倍速播放到结束，无媒体错误 |
| 公网 596 秒样本 | 1.51 s 开始推进，16 倍速播放到结束 |
| 37 / 63 / 12 秒 Seek | 327 / 309 / 311 ms 恢复 |
| 建流取消后重建 | 31 ms |
| 中途 Range 失败 | 2.13 s 明确失败，328 ms 重建恢复 |

### 控制面

| 操作 | p50 | p95 |
| --- | ---: | ---: |
| L1 能力缓存命中 | 4.22 µs | 4.92 µs |
| 热播放规划 | 3.86 µs | 4.45 µs |
| `MediaSource.isTypeSupported()` | 0.002 ms | 0.003 ms |
| IndexedDB 单键读取 | < 0.1 ms | 0.1 ms |
| loopback `control-v1` Range | 0.282–0.289 ms | 0.361–0.383 ms |

`control-v1` 数字只表示浏览器和本机协议开销，不包含上游解析服务、外部网络或 CDN 延迟。

### 扩展体积

| 产物 | 原始大小 | 加载时机 |
| --- | ---: | --- |
| Media Worker | 约 125 KiB | 建立兼容会话 |
| Mediabunny 核心 | 约 1.11 MiB | 建立兼容会话 |
| AAC Encoder | 约 975 KiB | 需要输出 AAC |
| AC3/EAC3 Decoder | 约 1.10 MiB | 选择 AC3/EAC3 转换 |
| DTS Decoder | 约 1.55 MiB | 选择 DTS 转换 |

音频 codec 为独立本地 chunk，普通 AAC、原生播放和纯转封装不会加载无关 codec。

## 发布门槛

| 指标 | 要求 |
| --- | --- |
| 原生路径额外成本 | p95 < 50 ms |
| 热播放规划 | p95 < 5 ms |
| 首个可播放分片 | p95 < 2 s，不含源站延迟 |
| Seek 恢复 | p95 < 2 s，不含源站延迟 |
| 主线程阻塞 | 热路径不得持续出现 > 50 ms 长任务 |
| 内存 | 不得接近整片驻留，达到预算后必须背压或清理 |
| 会话释放 | 停止后不得继续读取媒体或保留活动 Worker |

## 复现与失效

```sh
pnpm test
pnpm benchmark:control
```

修改 Range 块大小、并发、LRU、能力缓存、Mediabunny、codec 分包、fragment、MSE 预算、Seek
语义、媒体源协议或 Chrome 版本后，应重新测量受影响项目。真实 4K、HDR/DV、多标签和弱网体验
仍需在候选扩展中完成维护者验收。
